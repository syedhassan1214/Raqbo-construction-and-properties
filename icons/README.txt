RAQBO — brand icons
===================

The site includes these brand SVGs in this folder:

  google.svg      (Google sign-in "G" logo)
  whatsapp.svg
  instagram.svg
  facebook.svg
  pinterest.svg
  youtube.svg

google.svg      (Google sign-in)
whatsapp.svg    (WhatsApp)
instagram.svg   (Instagram)
facebook.svg    (Facebook)
pinterest.svg   (Pinterest)
youtube.svg     (YouTube)

The site loads these files in social links, sign-in, and WhatsApp contact buttons.
Keep this folder next to index.html when deploying. Official brand marks must be
used according to each platform's current brand guidelines.
