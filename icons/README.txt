RAQBO — official icons folder
=============================

Put the official icon files in THIS folder with exactly these names:

  google.svg      (Google sign-in "G" logo)
  whatsapp.svg
  instagram.svg
  facebook.svg
  pinterest.svg
  youtube.svg

The website picks them up automatically, in the header, footer, sign-in screen,
WhatsApp buttons and floating WhatsApp button. Any file that's missing keeps the
simple built-in icon, so nothing breaks.

Where to download them (official sources, free for linking to your profiles):
  Google     -> search "Google Sign-In branding guidelines" (developers.google.com)
  WhatsApp   -> search "WhatsApp brand resources"
  Instagram  -> search "Meta brand resources Instagram"
  Facebook   -> search "Meta brand resources Facebook"
  Pinterest  -> search "Pinterest brand guidelines" (business.pinterest.com)
  YouTube    -> search "YouTube brand resources"

Tips:
- Download the SVG version if offered. A PNG also works: name it e.g. whatsapp.png
  and change the name in the RAQBO SETTINGS block (brandIcons) in RAQBO_Website.html.
- Use the logo exactly as provided (no recolouring or stretching), as each brand's rules require.
- When you upload the website, upload this "icons" folder next to it.
