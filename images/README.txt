RAQBO website photos
====================
founder.jpg          -> Founder's photo (portrait, about 800 x 1000 px)
projects/...         -> Project photos (wide, 16:9, e.g. 1600 x 900 px)

After adding photos, open content.js and write their names, for example:
  photos: ['images/projects/residency-1.jpg', 'images/projects/residency-2.jpg']
Keep file names in lower case without spaces.
